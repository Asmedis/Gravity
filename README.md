# Gravity
Small gravity simulator using python

# Usage
```
python gravity.py
```
or
```
python3 gravity.py
```

# Controls
- Can set new object mass and wanted velocity xv, xy.
- To spawn new object press anywhere on the screen.
- To increase speed move the unnamed slider.
- Also options for following the current bigget object, tracing lines and velocity lines.
- Press Random to generate random objects.
- Press Start to start the simulation.
